# hueloft-site

Public web pages for the Hueloft game, served with GitHub Pages:

- `index.html`: landing page
- `privacy.html`: privacy policy (App Store "Privacy Policy URL")
- `support.html`: support and contact page (App Store "Support URL")

Publish: Settings › Pages › Source: *Deploy from a branch* › `main` / `(root)`.
The site is then live at `https://arthuryess.github.io/hueloft-site/`.
